# assets/ —— 素材目录

用户提供的素材统一放这里，按用途分子目录（拿到第一份素材时创建对应目录即可）：

| 子目录 | 内容 | 命名建议 |
| --- | --- | --- |
| `cards/` | 卡牌图（牌面插画） | 用卡牌 id，如 `shoot.png`、`medkit.png` |
| `characters/` | 角色立绘/头像 | 用角色 id，如 `gunner.png`、`rookie.png` |
| `ui/` | 界面素材（背景、牌桌、边框、图标） | 语义命名，如 `table-bg.jpg` |

尺寸建议：卡牌 ≥ 300×420（2:2.8），角色头像 ≥ 256×256。

用途：下一个里程碑（最小热座页面）直接引用；引擎本身不依赖素材。
